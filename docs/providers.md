# Providers

Kiyo routes across free model providers. Configure keys via env vars. Provider health is checked by `kiyo doctor`.
Primary (TODO(verify) until live-checked): OpenRouter, Google AI Studio, Groq, generic OpenAI-compatible.
Experimental: Cerebras, GitHub Models, Mistral, NVIDIA, SambaNova, Together, Hugging Face, Cloudflare, Ollama.
