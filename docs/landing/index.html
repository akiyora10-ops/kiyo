Everything you can extend is one file.

Providers, tools, agents, skills, themes, commands and hooks all load from a single typed file. No build config, no boilerplate.

providertoolagentskillthemecommandhook
// plugins/providers/my-provider.tsexport default definePlugin({  kind: "provider",  name: "my-provider",  baseUrl: "https://api.example.com/v1",  envVar: "MY_PROVIDER_KEY",  models: [{ id: "fast-1", tools: true, context: 128_000 }],  limits: { perMinute: 30, perDay: 1000 },})

Most coding agents ask for a subscription before you write a line. Kiyo asks for a terminal. Free models, a router that never stalls, and a plugin system small enough to read in one sitting.

Seven kinds of plugin. One file each.

provider

Connect any LLM and its rate limits.

plugins/providers/groq.ts
tool

Teach the agent a new action.

plugins/tools/grep.ts
agent

A persona with its own tool allowlist.

plugins/agents/reviewer.ts
skill

Reusable know-how written in markdown.

plugins/skills/refactor.md
theme

Make the terminal look like yours.

plugins/themes/dracula.ts
command

Slash commands, one file each.

plugins/commands/usage.ts
hook

Run code before or after any tool call.

plugins/hooks/lint.ts

Built to be read, changed and trusted.

Free models first

Routes across free tiers by default and shows your cost as $0.00 while you stay inside them.

Edits you can review

Every change arrives as a diff you approve, reject or edit, with undo and redo behind it.

Permissions that ask

Plan mode is read-only. Shell commands ask first. Dangerous commands are blocked unless you override them.

Sessions that resume

Pick up where you stopped with a single flag, or export the whole session to markdown.

Works in your repo

Reads KIYO.md and AGENTS.md, maps your project, and runs your tests after it edits.

Your first pull request, in five minutes.

Every plugin is a single file, so a contribution is small, reviewable and quick to merge.

Step 1

Scaffold

Generate the file, a test and a docs stub.

kiyo plugin new provider my-provider
Step 2

Fill it in

Add the base URL, models and limits.

kiyo plugin validate
Step 3

Open the PR

CI checks it and tells you exactly what to fix.

git push && gh pr create
